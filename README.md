# Kickstarter Campaign Success Factors (Excel)

Excel-based analysis of early Kickstarter campaigns to uncover what drives campaign success and convert those insights into practical recommendations for founders.

## Business context
Kickstarter is considering offering a consulting service to help creators run more successful campaigns. This project identifies patterns linked to higher success rates and turns them into a simple, actionable checklist for campaign planning.

## Key questions
- What campaign length tends to perform best?
- What pledge goals look realistic?
- Do some categories succeed more than others?
- What engagement signals (updates/comments) are linked to success?
- Does reward structure (funding levels) relate to backer count?

## Tools
- Microsoft Excel (data cleaning, EDA, charts / pivots)
- PowerPoint (stakeholder recommendations deck)

## Highlights
- **More funding levels** are associated with **more backers**, improving the chance of success.
- **Engagement matters**: successful campaigns show far more **updates** and **comments** than failed ones.
- **Longer duration isn’t a fix**: failed projects tend to run longer, suggesting “keeping it open” doesn’t solve weak demand.
- **Category differences**: some categories show much higher success rates (e.g., Dance/Theater/Music) versus lower-performing ones (e.g., Technology/Fashion).

## Recommendations
- Set a realistic goal (avoid over-reaching)
- Offer multiple funding levels to broaden backer entry points
- Actively communicate: post frequent updates and respond to comments
- Don’t rely on longer duration as a rescue strategy
- Consider category dynamics when positioning and messaging
